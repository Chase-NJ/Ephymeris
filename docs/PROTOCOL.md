# Wire protocol reference

> GENERATED by protocol/generate.py from protocol/schema.py — DO NOT EDIT.  
> Regenerate with `npm run gen:protocol` (or `python protocol/generate.py`).  

Protocol version **1**. Every command, event, error code and payload shape on the WebSocket between the frontend and the sidecar. The rules that govern the wire — connection lifecycle, the envelope, replay on connect, box numbers rather than ports, and how to change the schema — are in [ARCHITECTURE.md](ARCHITECTURE.md#wire-protocol).

One row per name: its type (a shape's field names) and the first sentence of its doc. Field types and the full description of every command, event, field and error is its `doc=` in `protocol/schema.py`, repeated as a doc comment in the generated `protocol.ts` and `protocol.py`. `name?` marks a field that may be absent, which is distinct from one whose type allows `null`; timestamps are ISO-8601 strings; `box` is always a box number 1–6, never a port address.

## Error codes

| Code | Meaning |
|---|---|
| `BAD_MESSAGE` | Malformed JSON, a non-object frame, or args that don't match the command's declaration here … |
| `UNKNOWN_COMMAND` | Unrecognized `cmd`. |
| `UNAUTHORIZED` | Missing or invalid token, or a first message that isn't `auth`. |
| `PROTOCOL_VERSION_MISMATCH` | `v` does not match the sidecar's protocol version; rejected rather than parsed best-effort. |
| `ILLEGAL_TRANSITION` | Operation not permitted from the port's current state (`ARCHITECTURE.md#port-state-machine`). |
| `SEND_NOT_PASSTHROUGH` | A console write (`port.send`, `port.sendStart`) to a port not in `PASSTHROUGH`. |
| `PORT_NOT_BOUND` | No board is bound to that box number. |
| `PORT_OPEN_FAILED` | Serial open failed — board absent, port busy, or permissions. |
| `SKETCH_UNKNOWN` | `flash.enqueue` or `port.sendStart` named a path outside the current discovery result. |
| `SKETCH_DECODE_ONLY` | `flash.enqueue`, `port.sendStart` or `sessions.confirmMapping` named a decode-only sketch (`TASKS.md#decode-only-sketches`): it is bundled so its … |
| `COHORT_NOT_FOUND` | No cohort with that id. |
| `COHORT_NAME_TAKEN` | Name already used by an **active** cohort. |
| `COHORT_INVALID` | A cohort validation failure (`DATA.md#cohorts-animals-and-groups`). |
| `COHORT_NOT_ARCHIVED` | `cohorts.delete` on a cohort that wasn't archived first — the deliberate two-step guard. |
| `ANIMAL_MOVE_REFUSED` | `cohorts.moveAnimals` with `apply` whose fresh plan can't go ahead, or whose records changed while … |
